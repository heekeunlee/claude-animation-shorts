# Claude로 애니메이션 숏츠를 만드는 과정

「쓰레기로 만든 바이올린」을 실제로 만들면서 거친 과정을 그대로 정리했습니다.

## 0. 준비

| 필요한 것 | 설명 |
|---|---|
| Claude Code | 터미널에서 쓰는 Claude. 모든 작업을 여기서 대화로 진행합니다 |
| Lemo-Opuscar 플러그인 | `claude plugin marketplace add lemomo-ai/lemo-opuscar` 후 `claude plugin install lemo-opuscar@lemolab` |
| Node.js, ffmpeg, Python 3 | 렌더(헤드리스 브라우저), 인코딩, 작곡·믹스 |
| (선택) Chrome 확장 | 참고할 유튜브·릴스 영상을 Claude가 직접 열어 보고 요약하게 할 때 (`claude --chrome`) |

처음 실행하면 Claude가 라이브러리를 `~/lemo-opuscar`에 받고, 필요한 도구와 악기 샘플(수백 MB)을 설치합니다.

## 1. 소재 찾기와 사실 확인

실제로 한 요청:

> 예전 다큐에 소개됐던 실화인데, 남미 빈민가 쓰레기장에서 음악 선생님이 쓰레기로 악기를 만들어 오케스트라를 만든 이야기 알아? 찾아보고 상세 히스토리, 시놉시스, 콘티 만들어줘

- Claude가 웹 검색으로 "카테우라 재활용 오케스트라"를 찾고, **확인된 사실과 확인되지 않은 소문을 나눠** 알려줍니다. 예: 카네기홀 공연은 확인되지 않음, 케네디 센터 공연과 메탈리카 오프닝은 확인됨.
- 관련 유튜브 링크를 주면(Chrome 확장 연결 시) 자막 대본을 읽고 화면을 캡처해 내용을 정리합니다. 원본 다큐 예고편의 인터뷰("사람도 함부로 버려선 안 된다")가 마지막 자막의 재료가 됐습니다.

## 2. 이야기 다듬기

> 감동적이고 울림 있는 이야기로 와닿게 만들어줘. 약 40초로 가능할까?

Claude가 바꾼 것:
- 마을 전체 설명 대신 **한 아이의 손**에 집중하고, 첫 장면과 끝 장면을 같은 손으로 맞추는 북엔드 구조.
- 음악을 **하나의 선율**로: 바이올린 초보가 처음 낼 수 있는 개방현(라·레)으로 시작해 오케스트라로 커지는 창작 테마.
- 첫 18초는 음악 없이 소음만, 첫 음 직전 2초 완전한 정적.

## 3. 화풍 고르기

> 섬네일로 어떤 그림체가 있는지 다 보여줘

66개 화풍의 대표 장면을 갤러리로 보여주고, 이야기에 맞는 화풍에 추천 표시를 해 줍니다([STYLES.md](STYLES.md), [갤러리](https://heekeunlee.github.io/claude-animation-shorts/)).
같은 이야기를 수채화와 80년대 셀 애니로 각각 만들었습니다.

## 4. 제작 (Claude가 자동으로 하는 일)

1. **구성안 `TREATMENT.md`**: 구조 후보 3개와 선택 이유, 샷 리스트(프레이밍·카메라·이유), 초 단위 비트 시트, 음악 큐 맵(80bpm, 마디마다 무엇이 들어오는지), 효과음 표, 자막 디자인.
2. **스타일 프레임**: 실제 그리기 코드로 몇 장을 렌더해 화풍 규칙과 대조합니다. 셀 애니는 캐릭터 모델 시트(얼굴, 손, 아이들, 악기)를 먼저 확인했습니다.
3. **그림 코드**: `story.js` 하나에 타임라인(장면, 자막, 이벤트)을 두고 그림·음악·효과음이 모두 이것을 읽습니다. 장면은 시간 `t`의 순수 함수라 어느 프레임이든 똑같이 다시 그려집니다.
4. **작곡 `music/score.py`**: 실제 악기 샘플(CC0)로 악보를 이벤트 목록으로 씁니다. 재활용 악기 느낌은 바이올린 샘플에 "깡통 몸통 공명" 필터를 입혀 냈습니다.
5. **믹스 `mix.py`**: 바람·파리·깡통·망치·박수 같은 효과음을 모두 합성하고, 장면 이벤트 시간에 정확히 맞춰 놓습니다.
6. **렌더와 마스터링**: 헤드리스 브라우저로 프레임마다 그려 영상을 만들고, 두 번 측정하는 loudnorm으로 −14 LUFS, 트루피크 −1.2 dB 이하로 맞춥니다.
7. **자기 검사**: 자막·라벨이 읽을 시간만큼 머무는지(readcheck), 검은 화면, 1.5초 간격 콘택트 시트 두 번.

## 5. 고치기

> 첫 장면 손을 더 자연스럽게 다듬어줘. 마지막 장면에 오케스트라 연주까지 넣고 50초로 늘리자.

- 손: 손가락 마디가 실제로 굽으며 쓰레기를 헤집고 병을 집어 드는 동작(위에서 본 손가락의 원근 축소, 손톱, 관절 주름).
- 결말: 첼로·색소폰 클로즈업 → 소녀 독주(역광) → 전체 오케스트라, 음악은 마지막 후렴을 반음 올림.

## 배운 것 (시행착오)

- **한국어 자막 읽기 시간**: 라이브러리 기본값(초당 4.5자)은 한자 기준이라, 한글은 초당 6.5자로 검사했습니다. 그래도 2줄 자막은 3~4.5초가 필요해서 40초 영상의 자막은 9줄이 한계였습니다.
- **라벨은 짧게**: "과자 깡통 → 몸통"은 읽을 시간이 모자라 "과자 깡통"만 남겼습니다.
- **음량**: 앞부분이 조용하고 뒤가 큰 영상은 전체 음량을 맞출 때 피크가 넘칩니다. 리미터를 좌우 채널 각각에 걸어야 했습니다.
- **세로 화면**: 렌더 도구 기본값이 가로(1920×1080)라 `--size 1080x1920`을 꼭 붙여야 합니다.
- **사람 그림이 가장 어렵다**: 손과 얼굴은 모델 시트로 먼저 확인하고, 반복해서 다듬어야 합니다.

## 법적·윤리적 주의

- 실화를 다룰 때: 사실은 자유롭게 쓸 수 있지만, 다큐·방송의 영상·사진·음악·인터뷰 음성·구도는 가져오지 않습니다.
- 실존 미성년자는 이름을 쓰지 않고 닮게 그리지 않습니다(대표하는 가상 인물로).
- 설명란에 "실화를 바탕으로 재구성한 애니메이션"임을 밝힙니다.
- 목소리가 필요한 영상은 상업적 사용이 허용된 TTS를 씁니다(무료 브라우저 음성은 약관을 확인).
