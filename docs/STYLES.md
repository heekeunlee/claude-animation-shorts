# 66가지 화풍 정리

Lemo-Opuscar 라이브러리의 화풍을 한국어로 정리했습니다. 썸네일은 [갤러리](https://heekeunlee.github.io/claude-animation-shorts/)에서 볼 수 있습니다.
"적합도"는 「쓰레기로 만든 바이올린」 같은 **인물 중심의 감동 실화**에 얼마나 맞는지입니다. 다른 이야기에는 다르게 맞을 수 있습니다.

Claude에게는 화풍의 영문 이름이나 폴더 이름(slug)으로 말하면 됩니다. 예: *"80s Cel Anime 화풍으로"*, *"paper-popup으로"*.

## 이야기 종류별 추천

| 이야기 | 잘 맞는 화풍 |
|---|---|
| 감동 실화, 인물 드라마 | 80년대 셀 애니, 수채화, 유화 임파스토, 펜 담채 스케치, 크레용 그림책 |
| 동화, 신화, 민담 | 종이 팝업북, 그림자극, 종이 라이트박스, 우키요에, 붉은 전지, 수묵화 |
| 역사, 옛날 이야기 | 1920년대 무성영화, 목판화, 동판화, 수묵화 |
| 과학, 지식 설명 | 화이트보드, 칠판, 등각 인포그래픽, 분해도, 현미경 이야기, 데이터 스토리 |
| 게임 같은 반전, 성장담 | 16비트 픽셀 RPG, HD-2D, 미니게임 연타 |
| 첩보, 미스터리 | 60년대 첩보 오프닝, 망점 수사 파일, 리미널 파운드 푸티지 |
| 코미디 | SF 시트콤 툰, 1930년대 고무호스 카툰, 50년대 플랫 카툰 |
